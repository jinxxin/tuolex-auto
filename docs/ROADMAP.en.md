# Roadmap

[简体中文](ROADMAP.md) ｜ **English**

This page lists what we plan to do and what we explicitly will not do. No dates are promised.
The Community Edition is maintained on a best-effort basis and absorbs upstream changes quarterly.

## Near term (v0.1.x)

- [ ] Upgrade the editor to Tiptap 3 (clears the current single moderate dependency advisory)
- [ ] Prebuilt images for linux/arm64 (Apple Silicon / ARM servers)
- [ ] More English issue templates and documentation (first batch done)
- [ ] Startup self-check hints (port / JWT_SECRET / database version)

## Next (v0.2, direction TBD)

- [ ] Import requirements and test cases from CSV / Excel
- [ ] API tokens: least-privilege tokens for automation
- [ ] Audit export: signed package with verification notes
- [ ] Observability: structured logs and richer health checks

## Explicitly out of scope

- No standards text bundled (ISO 26262 / A-SPICE PAM / IATF, etc.)
- No SaaS, multi-tenancy or billing
- No AI generation of requirements / HARA / safety cases
- No custom development (issues welcome; enterprise needs by email)

## How to influence the roadmap

Describe **the problem you are trying to solve** in [Discussions](https://github.com/jinxxin/tuolex-auto/discussions) or an issue — that is far more useful than "add feature X".
